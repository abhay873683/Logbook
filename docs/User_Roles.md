# TreeFlow AI - User Roles

## 1. Super Admin

### Responsibilities
- Manage all companies
- Manage subscription plans
- Manage system settings
- View all reports
- Manage platform users
- Control security settings

### Permissions
- Full Access

---

## 2. Company Admin

### Responsibilities
- Manage company profile
- Create departments
- Create teams
- Invite employees
- Manage projects
- View company reports

### Permissions
- Company Level Access

---

## 3. Manager

### Responsibilities
- Create projects
- Assign tasks
- Monitor team progress
- Generate reports
- Review employee performance

### Permissions
- Department Level Access

---

## 4. Team Lead

### Responsibilities
- Assign tasks to team members
- Review completed tasks
- Track daily progress
- Communicate with team

### Permissions
- Team Level Access

---

## 5. Employee

### Responsibilities
- View assigned tasks
- Update task status
- Add comments
- Upload files
- Track own progress

### Permissions
- Assigned Tasks Only

---

## 6. Client

### Responsibilities
- View project progress
- View reports
- Download shared files

### Permissions
- Read Only Access
