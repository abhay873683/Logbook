# TreeFlow AI - Detailed Roles & Permissions

## 1. Super Admin

### Description
The Super Admin manages the entire TreeFlow AI platform.

### Responsibilities
- Manage all companies
- Manage subscription plans
- Manage billing
- Manage platform settings
- Manage all users
- View all reports
- Monitor system activities

### Permissions
- Full Access

---

## 2. Company Admin

### Description
The Company Admin manages a single company.

### Responsibilities
- Create and manage departments
- Create and manage teams
- Invite employees
- Manage company projects
- View company reports
- Configure company settings

### Permissions
- Company Level Access

---

## 3. Manager

### Description
The Manager handles projects and teams.

### Responsibilities
- Create projects
- Assign tasks
- Monitor team progress
- Review completed work
- Generate reports

### Permissions
- Department Level Access

---

## 4. Team Lead

### Description
The Team Lead manages daily team activities.

### Responsibilities
- Assign tasks
- Review submitted tasks
- Track progress
- Help team members
- Update project status

### Permissions
- Team Level Access

---

## 5. Employee

### Description
Employees complete assigned work.

### Responsibilities
- View assigned tasks
- Update task status
- Upload files
- Add comments
- Complete subtasks

### Permissions
- Assigned Tasks Only

---

## 6. Client

### Description
The Client can monitor project progress.

### Responsibilities
- View project progress
- View reports
- Download shared files

### Permissions
- Read Only Access
